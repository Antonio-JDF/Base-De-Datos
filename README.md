				PASOS PARA EJECUTAR LA INTERFAZ GRÁFICA
1. En el paquete CONNECTION abrir ConnectionJDBC.java e introducir sus credenciales (login y contraseña).
2. Ejecutar como Java Application TestConexion.java para comprobar la conexión.
      Si en este paso da algún error en la terminal, compruebe las credenciales introducidas.
3. Comprobar en SQL Developer si están los datos están introducidos en la base de datos.
      Ejecutar DDL e inserts.sql.
4. En el paquete VIEW, ejecutar como Java Application MainFrame.java.
